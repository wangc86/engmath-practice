## 回覆（摘要；完整版見本輪最終訊息）

### 1. §1.7 併成一張表

那一節本來有兩張：一張記版次變動（正確），一張記「守的是什麼」（**錯的**
——還寫著 v0.28 的項數，並列著 v0.29 就移除的 `test_accounts.py` 與
`test_release.py`）。併成一張四欄的表（檔案／項數／守的是什麼／這個數字
怎麼變成現在這樣），已移除的兩個檔案保留為 ✂ 的列（項數欄是 `—` 而不是 0，
因為 0 會被相加）。

**理由記在該處**：一份資料放兩個地方，就會有一個先過期，而過期的那一個
看起來與正確的那一個一樣可信。

### 2. 相依性分析與新的測試規則（D65）

**答案是可以，而且省得比預期多；但那句「只有第一次下載到新機器才要跑全部」
需要補上四個例外。**

作法不是手寫對照表（v0.31 剛示範過那種東西會在搬檔案時安靜過期），而是
**實跑量出來**：`scripts/test_deps.py measure` 把每個測試檔跑一遍，記下它
import 了哪些模組、`open()` 了哪些檔案、`subprocess` 的 argv 與 env 裡有哪些
路徑，存成 `tests/data/test_deps.json`。`select` 再依 `git diff` 挑。

實測（8 個測試檔、1394 項、全套約 838 秒）：

| 這次改了什麼 | 要跑的 | 約幾秒 |
|---|---|---|
| 一個題型（例如 `ode/separable.py`） | 5 個檔案 + `-k` 窄化 | **312** |
| `app/generator/base.py`（共用） | 5 個檔案，不窄化 | 782 |
| 只有文件 | 無 | **0** |
| 新檔案／`requirements.txt`／`pytest.ini` | **全部** | 838 |

**`-k` 窄化**：`test_generators.py` 與 `test_web.py` 的參數化測試 id 裡帶著
完整的 `template_id`，所以可以只跑「改到的題型」**加上「id 裡沒有提到任何
題型的每一項」**——後面那一半保證了一項專門針對某個題型、但名字裡沒寫出
`template_id` 的測試照樣會跑。⛔ **誤差方向是多跑，不是少跑。**

⛔ **一定要全跑的四種情形**（寫在 `CLAUDE.md`「只跑相關的測試」那一節，
**那一段比省時間重要**）：換機器／換 Python 或 SymPy 版本；動過
`requirements.txt`／`pytest.ini`／`conftest.py`；`select` 說「地圖不認得
這些原始碼路徑」（多半是新檔案，而**一個忘了註冊的新 generator 正是沒有
任何測試會碰到它**）；以及要打 tag、push、或交給學生之前。

新增 `tests/test_test_deps.py`（8 項），守四種**只會讓測試變少、不會變紅**
的過期方式。⚠️ **但沒有任何測試守得住「地圖是最新的」**——要驗那件事就得
把全套再跑一遍，而那正是這整套機制要避免的。這句話寫在文件裡而不是省略。

### 3. 2c 的準備工作

`preview.html`（16 題型 × 3 難度 × 5 題 = 240 題）與
**`2c-PRESCREEN.md`**（`scripts/review_steps.py` 產生）。初篩用五項判準
（步驟顆粒度、`note` 在說「為什麼」還是「做了什麼」、難度階梯的三個可量
向度、英文用語分佈、附錄 C 的 $y$ vs $y(x)$），開頭是一份「先看這幾個」
的排序。⛔ **一句敘述都沒有改。**

三件把 §7 的待決從「感覺」變成數字的事：#11 只剩一組競爭說法真的兩種都在用；
#22 的步驟數中位數 6.1、範圍 4.0–10.1（兩倍半）；**#29 那句「已知至少一處
不一致」實際上是四處**——那句話從 v0.8 起就在，而沒有人回頭數過。

### 踩到的坑

**兩個，都在這一輪新寫的工具裡，而第二個是規則 4 的無聲降級**：

1. `note()` 把 `node -e <一整段 JS>` 當成路徑去 `stat()`，拋 ENAMETOOLONG，
   **讓一項本來會過的測試變紅**（`test_every_formula_renders_in_the_bundled_katex`）。
2. `op_count()` 對 `MutableDenseMatrix` 走進 `except: return 0`
   （`ImmutableDenseMatrix` 有 `count_ops`，Mutable 的沒有），於是四個系統
   題型的難度欄安靜地印出 `0→0→0`——看起來像「答案完全沒有變複雜」，
   其實是「根本沒量到」。⚠️ **它發生在一支用來找問題的工具裡。**
